# Code of conduct

Version française plus bas.

DrDXT follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, judge the code and the measurements, never the person. Harassment, insults, personal or
political attacks, and publishing someone's private information are not accepted, in the issues, the pull requests
or the Discord server.

## Reporting

Report a behaviour in private to the maintainer, [@ablanchard-dev](https://github.com/ablanchard-dev): the
**Security** tab of the repository, then **Report a vulnerability**, with "conduct" in the title. Every report is read
and answered; the person who reports is never named without their consent.

## What happens next

Depending on the case: a private warning, the removal of the message, a temporary ban, or a permanent ban from the
project's spaces, as described in the Contributor Covenant's enforcement guidelines.

# Code de conduite

DrDXT suit le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).
En bref : sois respectueux, juge le code et les mesures, jamais la personne. Le harcèlement, les insultes, les attaques
personnelles ou politiques et la publication d'informations privées d'autrui ne sont pas acceptés, ni dans les issues,
ni dans les pull requests, ni sur le serveur Discord.

Un comportement se signale en privé au mainteneur, [@ablanchard-dev](https://github.com/ablanchard-dev) : onglet
**Security** du dépôt, puis **Report a vulnerability**, avec « conduite » dans le titre. Chaque signalement est lu et
reçoit une réponse ; la personne qui signale n'est jamais nommée sans son accord. Selon le cas : un avertissement privé,
le retrait du message, une exclusion temporaire ou définitive des espaces du projet.
